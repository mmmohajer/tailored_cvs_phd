# custom_resumes/

Tailored output, one folder per position, matching the slug in `positions/`. Gitignored except this README.

Each folder holds four documents for that position:

| File | What it is |
|---|---|
| `cv.md` | Custom CV for this opening. Not a copy of the master |
| `cover_letter.md` | Cover letter for this opening |
| `professor_email.md` | Email to one professor. The agent does not send it |
| `follow_up.md` | When to send one reminder, and when to stop |

It also holds `recommender_notes.md`, `keywords.txt`, `match_report.md`, and `review.md`. When the page is silent, the country-default essay is added (`statement.md`, `research_proposal.md`, or `motivation.md`). When the page names its essays, those are written instead.

`examples/` is an earlier job-application walkthrough and is not the pattern for these files.
