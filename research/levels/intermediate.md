# Intermediate

About 2–5 years of full-time experience; titles like Software Engineer II.

## Findings

- Two-page resumes were preferred 2.6x for mid-level roles in a simulation, when the extra page carried real content. [S02, C]
- Recruiters scan titles, companies, and dates for steady progression. [S01, C]
- Exact-criteria filtering against the job description screens out qualified people. [S05, B]

## What the agent does

- **Length:** 1–2 pages. One page if everything relevant fits at 10pt+; two if real results would otherwise be cut.
- **Order:** Header → Summary → Skills → Experience → Projects (optional) → Education.
- **Story:** show growth from "built what was assigned" to "owned a feature or service end to end." Each role should show bigger scope than the last.
- **Bullets:** ownership of features or services, production results (latency, reliability, cost, revenue, users), code review and mentoring of interns or juniors.
- **Education:** one line at the bottom; no GPA or coursework.
- **Keywords:** mirror the posting's exact skill names for skills the person has (S05).
