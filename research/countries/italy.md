# Italy

Italian doctorates are filled by a call, a *bando*, and each doctoral sheet can set its own documents, language, and scores. There is no national page count in this folder. Do not copy a US statement into a concorso that scores a research project.

## Findings

- **The University of Bologna's 42nd-cycle notice tells applicants to check the individual doctoral sheet for the CV's language and format.** A national identity document is a separate upload. That notice does not set one CV length for every program.
- **One Padua curriculum prefers a Europass CV, reverse chronological, with the degree grade or the exam average easy to find.** Publications on that sheet use one citation style and omit conference talks that were not published in full. The research project there is capped at 2,000 words plus a bibliography, and it is scored separately from the CV. [S27, D] This is one curriculum, not Italy.

## What the agent does

The four files are always written: custom CV, cover letter, email to one professor, and a follow-up plan. The bando names the essay. When it is silent, write `research_proposal.md` if the route is a concorso that scores a project, and `motivation.md` if the route is a single advertised post. Say which choice was made in the match report. The cover letter does not replace either.

- **CV.** Facts live in `cv.md` in the default order in `research/format/cv_structure.md`: education, the matching research, publications on page one if any exist, awards, tools. Reverse chronological. The grade stays on the original scale and is easy to see. 1–2 pages when the bando is silent.
- **Europass.** If the bando prefers or requires Europass, the person builds that file in the official editor from these facts. This repository does not emit an Europass PDF. A photograph stays off unless the bando asks. Europass's general job-CV page mentions a photo. That is not this bando.
- **Proposal.** Only the project the person can actually describe. The word cap is the one on the sheet.
- A master's is the usual entry on the European pattern in the four-university comparison. [S15, B] Its absence is a gap to surface, not a detail to hide. That comparison did not include an Italian university.
