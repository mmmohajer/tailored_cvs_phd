# CV length, sections, and order

Checked 26 October 2026. There is still **no controlled study** of how many pages a PhD-applicant CV should be, or of which section order raises an offer. The numbers below are what universities tell applicants. They are grade D. A program's own limit wins over every row.

## How long

Early-career doctoral applications cluster at **one to two pages**. A third page appears only when the instructions allow it or the relevant record (papers, a long research history) will not fit in two. A faculty job CV is a different document and can run much longer. [S28, D]

| Place | What the page actually says | Use it for |
|---|---|---|
| Stanford Computer Science | Most applicant CVs are around 1–2 pages. Education, research, and publications belong on the first page. Move publications toward the top. A short list is fine. [S18, D] | US science and engineering applications when the department is silent |
| Boston University Graduate School | One page is typical with limited research. A second or third page is acceptable when the relevant record is long. Longer than that can bury the record. Publications may take about half a page. [S20, D] | The same US default. The third page is a ceiling, not a target |
| Oxford graduate admissions | Upload a CV only if the course page asks. When it does, the file is one or two pages: qualifications, publications, and relevant experience. The form's own fields, when no file is uploaded, are qualifications, employment, research, publications, presentations, prizes, and skills. [S19, D] | UK courses that ask for a file |
| Toronto, Statistical Sciences | Maximum two pages, single-spaced. [S21, D] | One Canadian department. Not a national cap |
| UBC career centre | An academic CV has no fixed length. A resume is 1–2 pages. In Quebec and parts of Europe the word "CV" is used for what other places call a resume. Section order varies by discipline. [S22, D] | Do not stretch a first PhD application to a faculty CV because this page allows length |
| DAAD doctoral scholarship | Tabular CV, maximum 3 pages. Publication list separate, maximum 10 pages on the Bonn page. [S16, D] | That scholarship. A university posting can set another cap |
| Bundesagentur für Arbeit | For job applications in Germany, the CV should not be longer than two pages. Reverse chronological inside sections. A photo is not mandatory and is still common. Marital status is not required. [S23, D] | German employment. It does not override a doctoral call or the DAAD 3-page cap |
| University of Amsterdam | A detailed CV with months, not only years. If there is a publication list, at most one A4 page. Two academic referees, with emails and the relationship. [S17, D] | Dutch vacancies when the posting is silent on length |
| NVP Recruitment Code | Ask only for information needed to judge suitability. Avoid requirements based on personal characteristics. [S24, D] | Why a Dutch CV omits a photo, age, and marital status unless the posting asks |
| Padua, one computer-science curriculum | Europass is preferred. Reverse chronological. The degree grade, or the exam average, should be easy to see. [S27, D] | That call. ## Sections, and whether order matters

No graded study says one order causes admission. The instructions that name sections agree on three things: education is present, research is present, and publications are present if they exist and are easy to find. Reverse chronological order inside a section is explicit at Oxford's form, Amsterdam, the Bundesagentur, Europass, and Padua. [S19, D; S17, D; S23, D; S27, D]

Default order when the page does not set one:

1. **Education.** Degree, institution, dates with months, thesis title, advisor, grade on the transcript's scale (X out of Y). [S25, D]
2. **The evidence this opening asked for.** Research, or a job that really used the method. Page one carries it. [S18, D]
3. **Publications**, on page one if any exist, next to the work that produced them. Status is exact. A verifiable paper includes its link. [S18, D; S25, D] Leave the section out if there is no paper. [S19, D]
4. **Teaching**, only if it happened and the posting cares.
5. **Awards**, the ones on the master. They are a normal section, not a personality list. [S19, D; S20, D]
6. **Methods and tools**, each one tied to an entry above.
7. **Languages**, as its own section when a test score or a native language is on the master. The REV01 CV keeps this apart from tools.
8. **References**, the people who have agreed, with the relationship and the email, when the page asks or when the person's own CV shape includes them. Both are true for the current file. [S17, D]

The person asked for two pages most of the time, using `profile/Niloofar Adelkhani-CV-REV01.pdf` as the section example: education, research experience, publications, work, languages, honours, and the two referees. Selection still drops a course or a job that this opening does not need. It does not drop research, publications, or languages to make a one-page file. Claims that appear only as wording on REV01, and not in the master, stay off. That includes a rank the master does not give the advisors, "large-scale" for the SQL work, and a date range that runs backwards.

Industry work stays when it is real evidence. It does not move above education. A job title is not relabeled as a lab.

### What changes by country

- **United States and Canada.** No photo, date of birth, marital status, or nationality. GPA stays on the original scale. Canada's silent default matches this shape. One Toronto department caps the file at two pages; UBC's career centre does not. [S21, D; S22, D]
- **United Kingdom.** Same academic shape. Upload the file only when the course asks, because Oxford removes a CV the course did not request. [S19, D]
- **Netherlands.** Months, not just years. The CV argues for one vacancy. A separate publication list is added only when the page asks for one apart from the CV, and then it stays within one page. [S17, D] No photo unless the vacancy asks. [S24, D]
- **Germany.** Tabular and reverse chronological. The DAAD cap is 3 pages for that scholarship. [S16, D] A photo, date of birth, and marital status stay off unless the saved call asks. The employment service says a photo is common and not required. Silence is not a request. [S23, D]
- **Italy.** Read the bando. When it prefers Europass, the facts in `cv.md` are the source and the person exports the Europass file from the official editor. This renderer does not pretend to be that editor. When the bando is silent on format, use the default order above, reverse chronological, grade visible, no photo. [S27, D] Europass's own job-CV tips mention a photograph. That line is general Europass advice, not an Italian doctoral rule, so the photo stays off unless the bando asks.

Coursework is a few named courses that prove a requirement. It is not a transcript pasted onto the CV.
