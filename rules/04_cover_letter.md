# Cover letter

Written in the same tailoring run as the resume, into `custom_resumes/<slug>/cover_letter.md`.

## Read first

`research/cover_letter/when_and_why.md`, `structure.md`, `ai_and_signal.md`.

## Steps

1. **Decide whether to write it** (`when_and_why.md`). If skipping, note why in `match_report.md`.
2. **Pick the proof story** from `master/stories.md` that best matches the posting's top requirement.
3. **Find the specific reason for this company.** Use what the person told you, or something concrete from the posting (product, mission statement, stack, team description). If neither gives a real, personal reason, write the best factual one and add a question for the person in `match_report.md` under "Edits for you."
4. **Write the letter** using `renderer/templates/cover_letter.md` and the four-paragraph structure in `structure.md`. 250–400 words. Today's date in `Month DD, YYYY`.
5. **Handle gaps honestly:** at most one sentence on a real gap from the match report and how it's being closed. Career switchers use the opening or fit paragraph for the bridge.
6. **Strip boilerplate** using the banned phrase list in `05_review.md`.
7. **Add "Edits for you"** to `match_report.md`: 2–4 specific places where the person's own words would make the letter stronger (always including the "why this company" sentence). Research [S19] found more editing time on AI drafts went with higher hiring success (observational).

## Rules

- Every number and claim traces to the master.
- Same header block as the resume.
- One page.
- Names a person only if the posting or the person provides a real name.
