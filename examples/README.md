# examples/

Four fictional people taken through an earlier **job-application** version of this repo (new grad, career switcher, intermediate, staff engineer).

They are kept so `renderer/scripts/render.py` can still be smoke-tested:

```bash
python renderer/scripts/render.py examples/jordan_rivera/master/master_resume.md
```

Do not copy their structure for a PhD application. The pattern for doctoral applications is `research/`, `rules/`, and the templates in `renderer/templates/`.
